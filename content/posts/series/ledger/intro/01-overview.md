## 이 글에서 할 일

Ledger는 **월급날 기준으로 흐르는 가계부**입니다. 구글 시트로 쓰던 가계부를 웹으로 옮기며 직접 만들었습니다. 이 글에서는 무엇을 만들었는지 먼저 둘러보고, 이후 글에서 어떻게 만들었는지를 하나씩 따라갑니다.

이 시리즈는 **완성된 Ledger 저장소를 기준으로** 작성합니다. 코드와 설정 파일을 읽으며 구현을 설명하고, 실행에 필요한 DB와 환경 변수를 준비해 같은 앱을 띄웁니다. 서버마다 달라지는 비밀번호와 API 키는 독자가 직접 설정해야 하므로, 해당 단계에서 파일 생성 위치와 입력할 값을 안내합니다.

## 시트에서 불편했던 세 가지

| 시트에서의 불편 | Ledger에서는 |
|---|---|
| 달이 바뀌면 남은 돈을 손으로 옮겨 적어야 했다 | **이월이 자동**입니다. 저장하지 않고 매번 계산하므로 과거 기록을 고쳐도 어긋나지 않습니다 |
| 월세, 통신비, 월급을 매달 다시 입력했다 | **고정 항목**을 한 번 등록하면 결제일에 알아서 기록됩니다 |
| 한 달의 기준이 1일이라 월급 흐름과 맞지 않았다 | **주기 시작일**(예: 25일)을 정하면 이월, 잔액, 오늘 쓸 수 있는 돈이 그 주기로 계산됩니다 |

세 가지 모두 "사람이 매달 손으로 하던 일"을 프로그램이 대신하게 한 것입니다. 이 시리즈의 [핵심 로직](/posts/ledger-domain-pay-cycle) 장에서 각각을 어떻게 계산하는지 다룹니다.

## 화면별 주요 기능

PC와 휴대폰 브라우저에서 같은 화면으로 씁니다.

| 화면 | 하는 일 |
|---|---|
| 대시보드 | 이번 주기의 이월, 수입, 지출, 잔액. **오늘 쓸 수 있는 돈** = (주기 잔액 − 아직 나가지 않은 고정 지출) ÷ 남은 날. 빠른 거래 입력 |
| 거래 내역 | 달력 월, 월급 주기, 최근 12개월, 전체 기간으로 조회. 검색과 필터, 추가, 수정, 삭제 |
| 고정 항목 | 수입과 지출을 등록하면 결제일에 자동 기록. 주말과 공휴일 보정, 카드 할부, 달러 결제 |
| 통장 | 통장별 잔액, 통장 사이 이체, 월급날 정기 이체 |
| 자산 | 통장, 적금, 주식 잔액표. 미국 주식은 시세로 자동 평가 |
| 요약 | 월별 수입과 지출 표, 막대 차트, 카테고리 도넛 차트, 결제수단별 지출 |
| 설정 | 카테고리와 결제수단, 주기 시작일, 시작 잔액, 공휴일, 비밀번호, CSV 내보내기 |

## 정리

- Ledger는 월급날 기준 주기로 이월과 잔액을 자동 계산하는 가계부입니다.
- 시트에서 손으로 하던 이월, 반복 입력, 기준일 맞추기를 프로그램이 대신합니다.
