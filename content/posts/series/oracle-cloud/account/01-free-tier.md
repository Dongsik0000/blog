## 이 글에서 할 일

웹 서비스를 인터넷에 올리려면 24시간 켜져 있는 컴퓨터, 즉 **서버**가 필요합니다. 집 컴퓨터를 계속 켜 둘 수도 있지만 전기, 고정 IP, 보안 문제가 생깁니다. 그래서 보통 클라우드 회사의 컴퓨터를 빌려 씁니다.

Oracle Cloud(정식 이름 Oracle Cloud Infrastructure, 줄여서 **OCI**)는 일부 자원을 기간 제한 없이 무료로 제공합니다. 이 글에서는 무료로 쓸 수 있는 범위를 정확히 이해합니다. 범위를 모르고 만들면 나중에 요금이 나오거나 서버가 회수될 수 있기 때문입니다.

## 무료 티어는 두 가지입니다

Oracle Cloud에 가입하면 두 종류의 무료 혜택이 함께 주어집니다.

- **Free Trial(무료 체험)**: 가입하면 받는 **미화 300달러 크레딧**으로, **최대 30일** 동안 유료 서비스에 쓸 수 있습니다. 30일이 지나거나 크레딧을 다 쓰면 끝납니다.
- **Always Free(상시 무료)**: 기간 제한 없이 계속 무료로 쓸 수 있는 자원 묶음입니다.

이 시리즈의 서버는 **Always Free 범위 안에서만** 만듭니다. 체험 크레딧이 끝나도 서버가 계속 돌아가게 하려는 것입니다.

체험이 끝나도 계정과 Always Free 자원은 그대로 남습니다. 하지만 체험 크레딧으로 만든 유료 자원은 유료 계정으로 업그레이드하지 않으면 Oracle이 회수합니다. A1 인스턴스도 마찬가지로, 체험이 끝날 때 모든 A1 인스턴스의 합계가 2 OCPU·12GB를 넘으면 전부 비활성화되고 30일 뒤 삭제됩니다. 그래서 체험 기간에도 처음부터 Always Free 범위로만 만듭니다.

> 크레딧 금액과 기간은 2026-10-16 Oracle 무료 체험 페이지 기준입니다. Oracle이 바꿀 수 있으므로 가입 전에 공식 페이지에서 한 번 더 확인합니다.

## Always Free로 쓸 수 있는 것 (2026-10-07 공식 문서 기준)

출처: Oracle Cloud 공식 문서 "Always Free Resources"

### 컴퓨팅 (서버 본체)

| 종류 | 무료 범위 |
|---|---|
| Ampere A1 (ARM 프로세서) | 월 1,500 OCPU 시간, 월 9,000 GB 시간. 상시 켜 두면 **2 OCPU, 메모리 12GB**에 해당 |
| AMD Micro | `VM.Standard.E2.1.Micro` 인스턴스 최대 2대, 각 1/8 OCPU, 메모리 1GB |

여기서 낯선 단어 몇 개를 풀어 보겠습니다.

- **OCPU**: Oracle이 쓰는 CPU 단위입니다. 1 OCPU는 물리 코어 하나 정도로 생각하면 됩니다.
- **OCPU 시간**: "OCPU 개수 × 켜져 있던 시간"입니다. 한 달을 약 750시간으로 보면, 2 OCPU 서버를 한 달 내내 켜 두면 1,500 OCPU 시간이 됩니다.
- **GB 시간**: 메모리도 같은 방식입니다. 12GB × 750시간 = 9,000 GB 시간입니다.

즉 ARM 서버는 **2 OCPU, 12GB 이하**로 만들면 한 달 내내 켜 둬도 무료입니다. 이 범위 안이라면 서버 한 대를 크게 만들어도 되고, 작은 서버 여러 대로 나눠도 됩니다.

AMD Micro는 메모리가 1GB라서 Java 웹 서버(Tomcat)와 데이터베이스를 함께 돌리기에는 부족합니다. 그래서 이 시리즈에서는 **Ampere A1**을 씁니다.

### 저장 공간과 네트워크

| 종류 | 무료 범위 |
|---|---|
| 블록 볼륨 | 부트 볼륨과 블록 볼륨 합쳐 **총 200GB**, 볼륨 백업 5개 |
| 외부로 나가는 데이터 전송 | 월 **10TB** |
| 로드 밸런서 | Flexible Load Balancer 1개 (10Mbps) |

- **부트 볼륨**: 서버의 C 드라이브 같은 디스크입니다. 운영체제가 설치됩니다.
- **데이터 전송**: 방문자가 페이지를 내려받을 때 서버에서 나가는 데이터의 양입니다. 개인 포트폴리오 수준이라면 10TB를 넘기기 어렵습니다.

## 반드시 알아야 할 두 가지 규칙

### 1. 무료 서버는 홈 리전에만 만들 수 있습니다

공식 문서에는 "모든 Always Free 컴퓨팅 인스턴스는 테넌시의 **홈 리전**에 만들어야 한다"고 적혀 있습니다. 홈 리전은 가입할 때 한 번 고르고 **바꿀 수 없습니다.** 그래서 가입 전에 리전을 신중히 골라야 합니다. 자세한 내용은 [홈 리전 고르기](/posts/oracle-cloud-account-home-region)에서 다룹니다.

### 2. 오래 놀고 있는 서버는 회수될 수 있습니다

Oracle은 다음 조건이 **7일 동안 모두** 참이면 인스턴스를 유휴(idle) 상태로 판단합니다.

- CPU 사용률의 95번째 백분위수가 20% 미만
- 네트워크 사용률이 20% 미만
- 메모리 사용률이 20% 미만 (A1 Shape에만 적용)

세 조건이 **모두** 맞아야 유휴로 판단한다는 점이 중요합니다. 웹 서버, 데이터베이스, 앱이 상시 떠 있는 서버라면 메모리를 꾸준히 쓰므로 이 조건에 걸리기 어렵습니다. 반대로 서버만 만들어 두고 아무것도 올리지 않으면 회수 대상이 될 수 있습니다.

## 확인하기

이 글을 읽고 나면 다음 질문에 답할 수 있어야 합니다.

| 질문 | 답 |
|---|---|
| ARM 서버를 무료로 상시 켜 두려면 최대 사양은? | 2 OCPU, 메모리 12GB |
| 무료 서버를 다른 리전에 만들 수 있나? | 없습니다. 홈 리전에만 만들 수 있습니다 |
| 디스크는 몇 GB까지 무료인가? | 부트 볼륨 포함 총 200GB |
| 서버가 회수되는 조건은? | 7일 동안 CPU, 네트워크, 메모리(A1) 사용률이 모두 20% 미만 |

## 정리

- 서버는 **Ampere A1**, **2 OCPU / 12GB 이하**로 만들면 무료입니다.
- 무료 서버는 **홈 리전**에만 만들 수 있고, 홈 리전은 바꿀 수 없습니다.
- 무료 범위와 규칙은 바뀔 수 있으니, 만들기 전에 공식 문서 "Always Free Resources"를 한 번 더 확인합니다.
